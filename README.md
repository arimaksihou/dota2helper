# Dota 2 Last Pick

Веб-MVP для выбора ластпика по роли, союзникам и героям противника.

## Важно

Приложение полностью отделено от Dota 2:
- не читает память игры;
- не подключается к процессу Dota 2;
- не меняет файлы игры;
- не устанавливает DLL/моды/оверлеи;
- работает как обычная веб-страница.

## Запуск

Самый простой вариант — GitHub Pages.

1. Создай новый репозиторий на GitHub, например `dota2-last-pick`.
2. Загрузи в корень репозитория:
   - `index.html`
   - `style.css`
   - `app.js`
3. Открой Settings → Pages.
4. В Source выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми Save.
7. GitHub выдаст адрес вида:
   `https://USERNAME.github.io/dota2-last-pick/`

## Данные

Герои и matchup-данные загружаются через OpenDota API прямо из браузера.

## Что улучшать дальше

MVP использует общие данные OpenDota и эвристику для позиции. Следующий этап — сделать более точную модель:
- patch-specific данные;
- отдельные рейтинги для каждой позиции;
- rank bracket;
- lane matchups;
- синергия союзников;
- ban-aware draft;
- confidence score;
- кеширование API;
- более точное объяснение рекомендации.
